# Elevator Simulator Web App

A parallel 3-elevator simulator for a 10-floor office building, built with **NestJS**, **React**, and **Socket.io**.


## Quick Start

Make sure you have **Node.js (>= 18)** installed.

### 1. Run Backend (NestJS)

```bash
cd backend
npm install
npm run start:dev
```

Server runs on `http://localhost:3000` (WebSocket Gateway ready).

### 2. Run Frontend (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

Web UI runs on `http://localhost:5173`.

## Tech Stack

- **Backend:** NestJS, TypeScript, Socket.io
- **Frontend:** React, TypeScript, Vite, CSS
